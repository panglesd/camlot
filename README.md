# Camlot: OCaml Operational Transform Library

Small OCaml Operational Transform library used in
[sliphub](https://github.com/panglesd/sliphub) for collaborative editing with
[codemirror](https://codemirror.net/). I added Code mirror's [collaborative
editing plugin](https://www.npmjs.com/package/@codemirror/collab) OCaml bindings
in [this repo](https://github.com/panglesd/jsoo-code-mirror/tree/collab).
